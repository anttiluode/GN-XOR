Two sources converge on a receiver through the original setpoint_mod port. The same positive event in both sources can suppress the receiver instead of strengthening it. No XOR condition is coded in the receiving neuron.

02 / The ring supplies its own prediction

The eight blue-green nodes are native relays, each passing a beat to the next. The circulating pattern is seeded once, then returns every 32 ticks. The world signal is compared with one ring node at a separate, native nonlinear receiver.

One source beat moves around the ring every four ticks. The ring is a physical simulation of the original dynamical update, not a rotating bit icon.

03 / Where this ends — for now

Demonstrated: a synchronized event-presence XOR in native geometric units and a ring-driven mismatch signal. Not demonstrated: learned prediction, symbol identity, robust asynchronous comparison, neuronal biology, or useful general intelligence. We keep the unusual behavior without inflating what it proves.

Exact circuit and reproducibility

All units use the V27 lookup table of 600 square sizes, the original four-tick pipeline and the 50-sample variance term. Edges from A and B to C are −4.5 by default. Ring edges are −6.0, and the ring has eight nodes. A source pulse of −10 is applied for two ticks through setpoint_mod. Ring recurrence needs no repeated prediction injections.
